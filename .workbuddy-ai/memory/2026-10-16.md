## WHITE SCREEN — root cause found & fixed (15:30)
**Cause was NOT the translation work.** `AppRoutes` in `frontend/src/App.tsx` declared
`useState`/`useNavigate`/`useEffect` **after** three conditional early returns
(`if (loading)`, `if (error)`, `if (!user) return <DemoLogin />`) — a Rules of Hooks violation.
Hook count changed between renders → React threw → blank white screen, triggered right after auth
succeeded. Pre-existing in HEAD (verified via `git diff`: the user's edits only added i18n lines).

**Fix applied (structural, behaviour-preserving):** split the authenticated subtree into a new
`AuthenticatedApp()` child component. Guards stay in `AppRoutes` (only `useLanguage` + `useUser`
above them, so the hook count is constant); every other hook now lives in `AuthenticatedApp`, which
mounts only when `user` exists. Added `if (!user) return null;` **after** all hooks in
`AuthenticatedApp` purely to restore TS narrowing (legal — a guard after hooks is fine; before is not).
`RoomsList.tsx:235` quoted-literal bug was already fixed by the user by the time I got there.

**Lesson:** when a React screen goes blank, check hook ordering before suspecting the recent edit.
